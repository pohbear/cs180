CS180 Project 1

Images of the Russian Empire

My attempt at turning Sergei Prokudin-Gorskii's three black-and-white exposures into color photographs by automatically aligning their blue, green, and red channels.

Overview Single-scale Image pyramid My examples Better features

Overview

From Three Exposures to One Color Image

Prokudin-Gorskii photographed the same scene three times through blue, green, and red filters. The digitized plate stores those exposures vertically in BGR order. The general idea is simple: split the plate into three equal images, keep blue as the reference, shift green and red until they line up with blue, and then stack them back together in RGB order.

  1. Split the plate: divide the height by three and extract the B, G, and R grayscale images.
  2. Ignore the borders: I remove 10% from each side while scoring because the black and white plate edges contain weird stuff that is not part of the photograph.
  3. Search for a displacement: test possible (dy, dx) shifts and compare only the region shared by both channels.
  4. Reconstruct the color image: apply the best shifts and stack the aligned channels as red, green, and blue.

Part 1

Single-Scale Alignment

My first approach was a straightforward exhaustive search. For each green or red channel, I tried every integer displacement inside a [-15, 15] × [-15, 15] window. That gives 961 possible shifts. For each one, I compared the valid overlapping region against the blue channel and kept the best score.

L2 distance

sqrt(mean((reference - moving)²))

L2 measures the average pixel difference, so a lower score is better. It is simple and worked well on the small images, but it can struggle when the same object has very different brightness across color channels.

Normalized cross-correlation

dot(A - mean(A), B - mean(B)) / (||A|| · ||B||)

NCC removes each region's mean and normalizes its length before comparing them, so a higher score is better. This makes it less sensitive to a general brightness difference, although it does not completely solve channel-dependent color differences.

Both metrics found the same shifts for the three low-resolution images. Since every correct displacement is inside the small search window, there was no need for a pyramid yet.

Part 2

Coarse-to-Fine Image Pyramid

Searching only 15 pixels in each direction is not enough for the large TIFF files, while making the full-resolution window much larger would be really slow. I handled this by repeatedly resizing both channels to half their width and height with anti-aliasing, creating a Gaussian pyramid from the original image down to a small version.

Step 1

Start small

At the coarsest level, a large original displacement becomes only a few pixels, so I search the normal ±15 window around (0, 0).

Step 2

Double the estimate

When moving to the next finer level, one coarse pixel becomes two pixels. I therefore double the previous (dy, dx) estimate.

Step 3

Refine nearby

I search only ±2 pixels around the doubled estimate, update the shift, and repeat until I return to the full-resolution image.

This was much faster than doing one massive search. On my runs, the large images generally took around four seconds each with the L2 metric. The gallery below contains the full set of provided images. All offsets use (dy, dx) and describe the shift applied to green or red to align it with blue.

Part 3

Additional Images I Chose

I also tested the same fixed pyramid settings on four more plates from the Prokudin-Gorskii collection. I did not tune the search window separately for each photograph. This was mainly to check that the approach could generalize beyond the provided examples instead of only working on images I had already seen.

Bells & Whistles

Better Features: Sobel Edge Alignment

The main failure case was Emir. His robe has a very strong blue color, so the same physical region appears with very different intensity in the three filtered exposures. Raw-pixel NCC assumes that the brightness patterns should still correlate, and it selected a clearly wrong red shift of (96, -250). This produced the obvious doubled face and robe shown below.

To improve this, I applied a small Gaussian blur with σ = 1.0 and then used a Sobel filter to build a normalized edge-magnitude image for each channel. I ran the same NCC pyramid alignment on those edge images, but applied the recovered shifts to the original grayscale channels. This lets the algorithm compare structural boundaries instead of relying as heavily on the channels having similar raw brightness.

The edge-based result lines up the outline of his robe, face, and the doors much better. There are still colored borders around the outside of the plate because my final crop only removes pixels made invalid by the shifts; it does not try to automatically detect and remove the original glass-plate borders.
