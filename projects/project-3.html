CS180 Project 3

Fun with Flow Models!

My attempt at turning noise into images, making pictures with two perspectives, and training a flow model of my own.

Overview Part A Image editing Anagrams Hybrids Part B Class sampling Reflection

Overview

From Noise to Images

My attempt at using flow models to clean up images, generate new ones, and make a few optical illusions. Then, instead of relying on a pretrained model, I train my own model to generate MNIST digits.

The general idea is simple: start with noise and learn how to move it toward an image. Part A explores what a pretrained model can do. Part B builds a smaller version from scratch, starting with a one-step denoiser and adding time and class conditioning.

Part A

Exploring a Pretrained Flow Model

For this part, I use PixNerd-XXL-P16-T2I at 512 × 512 resolution. My base seed is 723, and the Euler step size is 0.02. The basic denoising tests use the prompt a high quality photo. Guided sampling and the creative experiments use CFG weight w = 7.

xₜ = (1 − t)ε + t x₁   ·   t = 0: noise   ·   t = 1: clean image

I use the same landscape image and sampled noise throughout the reconstruction tests. This keeps the input consistent when I compare methods.

Part A · 1.1

Constructing Noisy Training Inputs

I interpolate between the image and Gaussian noise. This scales both terms; it is different from adding noise to an unchanged image. Smaller t leaves less of the original image, while larger t keeps more of it.

I also check the endpoints: t = 0 returns the noise exactly, and t = 1 returns the original image.

Part A · 1.2

Classical Denoising

As a baseline, I divide each noisy input by t to restore the image amplitude, then apply a Gaussian blur. Dividing by t also amplifies the noise, so the lower-t inputs are harder to recover.

xₜ / t = x₁ + ((1 − t) / t)ε

I test σ = 1, 2, 4, 8, and 16 and select the smallest reconstruction MSE against the known original for each input. This is an evaluation choice with access to the original, rather than a blind denoising rule.

Part A · 1.3

One-Step Denoising

The flow model predicts velocity, rather than the clean image directly. I multiply that prediction by the remaining time and add it to the current noisy state.

x̂₁ = xₜ + (1 − t)vθ(xₜ, t, c)

Part A · 1.4

Visualizing Velocity

Because I know both the original image and the sampled noise, I can compute the ground-truth velocity. I compare the actual update needed to reach the original with the model’s predicted update.

v_gt = x₁ − ε
predicted update = (1 − t)vθ
target update = x₁ − xₜ
error = sqrt(mean over RGB of (predicted update − target update)²)

The updates use one shared signed display scale, with zero at middle gray. The heatmaps use one shared linear scale across all three times. These display mappings do not change the raw errors.

Part A · 1.5

Euler Sampling

Instead of extrapolating all the way to the endpoint in one step, I repeatedly take a small step and ask the model for a new velocity. Starting at t = 0.50 with h = 0.02 takes 25 updates to reach t = 1.

x_next = xₜ + Δt × vθ(xₜ, t, c)

On this image, one-step denoising has the lowest MSE. More sampling steps do not guarantee a closer pixelwise reconstruction: the model follows its learned velocity field, rather than knowing the original image. The notebook also passes the constant-velocity tests for 50 steps, 25 steps, and a shortened final step.

Part A · 1.6

Generating Images from Noise

I start from independent Gaussian noise at t = 0 and integrate for 50 steps. The prompt stays fixed at a high quality photo; only the initial noise seed changes.

Observation: What does the generic prompt generate?

The generic prompt of "a high quality photo" outputs mainly portraits. This is true even with the default seed. Seed 724 is the outlier, and seems to be an image of someone holding a menu or pamphlet of some kind, with illegible text on it. I think it is also worth mentioning that seed 727, although heavily distorted/artifacted, still has a human silhouette. Maybe the prompt leans towards a photographic style that focuses more on the shape and layout of the person instead of the finer details like facial features. However, these are just my observations and I think the sample size is too small to make a generalised claim.

Part A · 2.1

Classifier-Free Guidance

I evaluate the same image and time twice: once with the text prompt and once with the empty prompt. CFG pushes the prediction farther in the conditional direction. In this notebook’s convention, w = 0 is ordinary conditional sampling.

v_cfg = v_c + w(v_c − v_u)   ·   w = 7

These use the same five initial noises as Section 1.6, making it possible to compare each seed before and after guidance. The w = 0 equivalence assertion also passes in the notebook.

Observation: How did guidance change the results?

Using the CFG produced more consistent portrait style results across the same seeds. The difference is clear for seeds 724, where it went from some menu with illegible text to a portrait of a man. The distortions from 1.6 in seed 727 are also reduced substantially. The guided outputs also have clearer facial features. They also have more consistency to their form.

Part A · 3.1

Image-to-Image Editing

I interpolate an input image with noise at a chosen starting time, then denoise from there using the generic photo prompt and CFG. Smaller starting times retain less of the input and give the model more room to change it.

Every comparison includes the original followed by starting times 0.02, 0.04, 0.06, 0.10, 0.14, 0.25, and 0.50. I reuse the same noise seed within the sweep.

Part A · 3.2

Text-Guided Image Editing

I keep the same images, starting times, seed, and editing function, but replace the generic prompt with one that describes the desired edit. This lets me compare how the input structure and text prompt affect the result.

Observation: Where is the best balance?

The text prompts seem to have a lot more strength/influence at the smaller starting times. For the Campernile, t=0.02 to t=0.06 clearly show a cargo ship and water, while from t=0.14 onwards the structure of the tower is more preserved.

The landscape to cat also shows the same tradeoff. Small starting times produce very close-up cat faces (albeit a bit distorted), with t=0.10 being a good intermediate results where the mountains and water provide structure for the cat's face. From t=0.25 onwards, the cat is missing and the original scenery dominates.

For the cat to sphinx, the useful immediate results are around t=0.10 to t=0.14. The output image retains the sitting pose from the cat and the background colours, while incorporating sphinx-like details and features. At t=0.50, although there are a lot of distortions, the cat heavily dominates.

Part A · 3.4

Hybrid Images

Instead of combining different orientations, I combine frequency bands of the guided velocity predictions. The distant prompt supplies low frequencies, while the close prompt supplies high frequencies. This happens at every Euler step, rather than blending two finished images afterward.

v = lowpass(v_distant) + v_close − lowpass(v_close)

The Gaussian low-pass uses σ = 16 and a 265 × 265 kernel at 512 × 512 resolution. Hovering shrinks the displayed image to one eighth of its width, simulating a farther view.

Observation: Does the interpretation change with size?

In the flowers–heart hybrid, the flowers are easy to recognize at the larger display size. When the image becomes smaller, the individual petals become harder to see and the broader arrangement together with the use of red becomes more suggestive of a heart. However the flowers are still visible, making the change more subtle.

The foliage-woman hybrid is not as strong. The leaves and branches, while clear at the larger size, do not show what I expect to be complete foliage. Meanwhile, the woman's silhouette is visible but I cannot really make out facial features that show the "intense gaze".

The results show that combining frequency bands does not automatically guarantee a clear change in perception. It also took me many iterations before I managed to arrive at images that I felt like were good enough.

Part B

Flow Matching from Scratch

For Part B, I train on MNIST instead of using the pretrained image model. The inputs are 28 × 28 grayscale images normalized to [0, 1]. I use seed 180, train only on the training split, and visualize results on held-out digits or fixed noise seeds.

Experiment Hidden D Epochs Batch Adam learning rate
Single-step denoiser 128 5 256 10−4
Independent pure-noise denoiser 128 5 256 10−4
Time-conditioned flow 64 10 64 10−2 + exponential decay
Class-conditioned flow 64 10 64 10−2 + exponential decay
Class flow, no scheduler 64 10 64 Constant 10−3

Part B · 1.1

Building the UNet

The UNet encodes the image through downsampling blocks, then upsamples it back to the input resolution. Skip connections concatenate encoder features with decoder features at matching spatial resolutions.

28 × 28 × D → 14 × 14 × D → 7 × 7 × 2D
→ 1 × 1 × 2D → 7 × 7 × 2D → 14 × 14 × D → 28 × 28 × D → 28 × 28 × 1

The blocks use convolutions, batch normalization, and GELU. The output layer predicts one grayscale channel. The downloadable notebook contains all of the simple and composed blocks.

Part B · 1.2

Adding Noise to MNIST

For the single-step denoiser, I add Gaussian noise directly to a clean digit. This is different from Part A’s interpolation: the clean image is not multiplied by t.

z = x + σε   ·   ε ~ N(0, I)

Part B · 1.2.1

Training the Single-Step Denoiser

I train a D = 128 UNet for five epochs to reconstruct clean digits from inputs with σ = 0.5. Each batch receives freshly sampled noise, so the model does not see exactly the same corrupted images in every epoch.

loss = mean((Dθ(x + 0.5ε) − x)²)

Each row shows the clean digit, noisy input, and reconstruction. The same ten test images and fixed noise tensor are used at both checkpoints.

Part B · 1.2.2

Out-of-Distribution Noise

The model was trained only at σ = 0.5. I test the same digit and noise pattern at a range of noise levels to see how its reconstruction changes away from the training setting.

The displayed outputs remain digit-like, but the highest-noise inputs are more ambiguous. Clipping to [0, 1] is only used to display the results; the model receives the noisy tensors directly.

Part B · 1.2.3

Denoising Pure Noise

I train a fresh UNet using independent Gaussian noise as the input and clean digits as the targets. There is no longer a digit signal in the input telling the model which target it should reconstruct.

Under squared error, the optimal predictor is the conditional mean E[x | z]. Since z is independent of the target digit in this experiment, this reduces to E[x]: the average training image. This explains why minimizing the loss can lead to similar blurry outputs rather than distinct sampled digits.

Observation: Describe the averaging you see

The pure-noise model produces very similar blurry, loop-like shapes for different noise inputs. This behavior appears after both one and five epochs, and the outputs resemble the displayed training-set mean rather than a diverse collection of individual digits.

I think this happens because the input noise is independent of the target digit. There is no information within the input that differentiates or identifies which digit to construct. Under MSE loss, the model learns what an average output should look like instead of different digits.

Part B · 2.1

Adding Time Conditioning

For flow matching, the model needs to know where it is along the path from noise to a digit. I embed the scalar time t using two fully connected blocks and use those embeddings to modulate the decoder features.

xₜ = (1 − t)x₀ + tx₁
target velocity = x₁ − x₀
loss = mean((uθ(xₜ, t) − (x₁ − x₀))²)

Time is sampled continuously in [0, 1] during training. The num_ts argument sets the sampling resolution in the surrounding interface; this training function does not quantize the random training times.

Part B · 2.2

Training the Time-Conditioned UNet

I train the D = 64 model for ten epochs with batch size 64. Adam starts at 0.01, and the exponential scheduler multiplies the learning rate by 0.11/10 after every epoch, taking it to 0.001 after ten scheduler updates.

Part B · 2.3

Sampling with Time Conditioning

At test time, I start with Gaussian noise and take 50 Euler updates from t = 0 to t = 1. I reuse the same seed at each checkpoint so the panels compare how the model changes during training.

These are unconditional digit samples: no class label tells the network which digit to produce. Several outputs are recognizable, while others have ambiguous or irregular strokes.

Part B · 2.4

Adding Class Conditioning

I encode the digit label as a one-hot vector and add two class-embedding blocks. During training, I drop the class condition on 10% of examples by setting that vector to zero. This lets the same network provide conditional and unconditional velocity predictions.

decoder feature = class_embedding × feature + time_embedding

Part B · 2.5

Training the Class-Conditioned UNet

I keep the ten-epoch schedule, D = 64, batch size 64, and initial learning rate 0.01. The difference is that the model now receives the class information, with dropout probability 0.1.

Part B · 2.6

Class-Conditioned Sampling

I generate four instances of each digit, using 300 Euler steps and guidance scale γ = 5. The columns are labeled 0 through 9, and each row contains one sample for each class.

v = v_unconditional + γ(v_conditional − v_unconditional)   ·   γ = 5

This guidance convention differs from Part A’s v_c + w(v_c − v_u). Here, γ = 1 would give the ordinary conditional velocity.

Removing the learning-rate scheduler

For a separate run, I remove the scheduler and reduce Adam’s constant learning rate to 0.001. The architecture, ten training epochs, batch size, class dropout, sampling steps, guidance scale, and seed remain the same. The smaller fixed step size is the compensation I test for losing the decay schedule.

Observation: Did the simpler scheduler preserve quality?

I removed the exponential scheduler and used a constant Adam learning rate of 0.001 instead of starting at 0.01. The no-scheduler run produces recognizable digits early in training, and its epoch-ten samples appear broadly comparable to those from the scheduled run.

Both final grids generally follow the requested classes, with some differences in individual appearances. The smaller constant learning rate seems to preserve visual quality without the scheduler.

Reflection

What I Learned

Main takeaway

The editing and illusion experiments also showed me that a plausible image is not necessarily a successful result for the intended task. An edit needs to balance the prompt with the original structure, and an illusion needs both interpretations to remain recognizable. It is not enough to just look at the data and numbers, the actual visual perception of the images are also key in determining the success of the task.
